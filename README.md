# 小小逻辑侦探：微信小游戏原型

## 运行

在微信开发者工具中导入本文件夹，项目类型选择“小游戏”，使用测试号或自己的 AppID 编译预览。请在手机上检查界面和触摸交互。

## 当前内容

- 二年级：5 个关卡，每关 5 题，共 25 题；每关至少答对 3 题解锁下一关，按正确数获得星星。
- 一、三、四、五年级：每个年级 10 道同题型的体验题，随机抽取 5 道，不含关卡。
- 提供题目提示、答案解析、错题回顾以及最近 20 次练习记录。
- 进度与记录仅保存在本机；清除小程序数据、换设备后可能丢失。

题目未经儿童试玩或教育专业审核，不承诺训练效果或对应课标。当前版本没有语音、账号、广告、付费或云同步；尚需微信开发者工具和手机真机验证。正式上线前应确认平台类目、备案及相关资质。
