# 小小逻辑侦探：微信小游戏

## 运行

在微信开发者工具中导入本文件夹，项目类型选择“小游戏”，使用自己的 AppID 编译预览。入口是 `game.js`，无需安装 npm 依赖。请在手机上检查页面滑动、文字大小和触摸交互。

## 主线内容

主线按**二年级上学期入门**重新设计，包含 **4 章、20 关、200 道题**。侧重观察、分类、简单规律、位置、一两步排除和小数目加减；不要求乘除法、跨整点时间计算、坐标、真假话、鸡兔同笼、最不利情况或集合去重。题干以短句为主，提示与解析使用短句；每关是一个小委托，按线索顺序穿插十种不同题型；选项顺序随机变化。生活小谜题穿插在不同关卡中。

这是思维练习的设计目标，不是课标逐课同步教材；孩子的识字量、学校进度和独立体验仍需通过试玩确认。

| 章节 | 关卡 | 主要内容 |
| --- | --- | --- |
| 线索起步 | 1—5 | 小猫、图书馆、彩旗、生日与花园；穿插观察、分类、规律和数量 |
| 小镇寻宝 | 6—10 | 点心店、小鸭、玩具列车、画笔与邮局；穿插位置、排序和加减 |
| 线索拼图 | 11—15 | 运动会、寻宝图、种子、气球与厨房；穿插配对、图案和顺序 |
| 校园委托 | 16—20 | 校园寻路、钥匙、书角、包裹与庆典；穿插地图、算式和筛选 |

- 每关 10 题，答对 6/8/10 题获得 1/2/3 星；至少 1 星解锁下一关。
- 每题两步提示、逐步解析；提示不扣星。十题全对且未用提示，额外记录“独立满星”。
- 每章累计 10 星获得章节徽章，共可收集 4 枚；称号随主线总星数提升。
- 每日挑战：每天 10 道不同题。首次开始时固定当天范围，之后升级、重试或重启题组不变；从已解锁关卡选题；第一关已有 10 题，不改变关卡解锁。完成后保留当日最佳成绩，最多保留最近 90 个挑战日期。旧版五题每日成绩不与新成绩混用。
- 错题档案：每次抽取最多 10 道，答对移出；学习记录保留最近 50 轮，各题型正确率包含重玩、提示作答与复习。
- 所有页面支持上下滑动，长题目和解析可以完整查看。不设置倒计时。
- 一、三、四、五年级保留原版体验题，尚未按本次主线方式扩展。

## 题目画板

- 彩旗、书架、圆片和图案直接画在题目下方，可点按做记号；左右位置保持在同一行。
- 排队和生活顺序：先点一张卡，再点另一张交换位置；比较排序也可用卡片尝试。
- 配对表：题目已明确的配对与排除自动标出，其他空格可循环标记勾、叉、清除。
- 补数、送出：点空位补圆片或点圆片划掉，再点可撤销；不自动作答。
- 3×3 数阵：点问号可试填 1、2、3，先看一行，再核对一列。
- 走图：用上、下、左、右箭头试走，可回到起点；没有坐标或路线总数计算。
- 画板操作不计分、不计提示次数、不保存到错题；仍需选择答案才提交。答题后画板停止编辑，并展示排队、配对、数阵和路线的正确结果；下一题重新准备画板。

## 页面与交互

- 统一使用森林绿、奶油白与暖金色；首页增加侦探矢量插画、星星/关卡/徽章统计与明确的继续调查入口，小屏自动压缩首页展示区。
- 「侦探社 / 案件地图 / 我的档案」固定底部导航；答题与成果页聚焦当前调查，不显示底部导航。
- 章节卡显示星数进度，关卡区分当前、已通过与待解锁；答题选项增加字母标记及对勾/叉号，答案状态同时用形状、颜色和文字表达。
- 卡片按压反馈、页面与提示淡入、答对小彩屑、成果星星依次弹出；右上方「动效 / 静态」按钮可切换并保存偏好。
- 所有图标与插画由 `ui.js` 直接绘制，不依赖网络、额外字体或图片素材。动画只在交互后短时运行，结束或切入后台即停止；缺少帧 API 时显示静态结果。
- 顶部操作放在标题下一行，为微信胶囊预留位置；所有长页面保留滑动和滚动指示。

## 存档与兼容

当前版本使用 `detective-v6` 存档，保存新主线的星星、解锁、错题、每日挑战和学习记录。启动时清理本机 `detective-v1` 至 `detective-v5` 旧存档，并移除当前存档中此前导入的旧版练习记录；当前版本的进度不受影响。

退出未完成的一轮不会保存通关结果，但已答题的错题和题型统计会保留。

所有数据仅在本机保存；换设备、删除小游戏数据后可能丢失。个人工具设置 `project.private.config.json` 不提交到 Git。

## 离线检查

安装 Node.js 后可运行：

```bash
node --check game.js
node --check content.js
node --check ui.js
node tests/game.test.js
```

检查覆盖全部 200 道题的独立答案校验（配对与排序穷举、数阵行列检查、路线按题干走图、算式代入）、短题干与知识范围、解锁和星星、重复点击、提示、错题复习、每日挑战范围固定与重启恢复、旧存档清理与当前进度保留、异常存档、小屏滚动、底部导航、画板交互及不计分、按压取消、动画结束/后台停止与动效偏好持久化。画布使用离线模拟，不能代替微信开发者工具和手机真机验证。
